# iOS SDK

The Lucia Metrics SDK for iOS provides device fingerprinting, touch event
tracking, and session management for native iOS apps.

- [Installation](./installation.md)
- [Initialization](./initialization.md)
- [Compliance & Privacy](./compliance.md)
- [Touch Event Tracking](./touch-events.md)
- [Security](./security.md)

## Requirements

- iOS 14.0+ (touch tracking requires iOS 17+)
- Swift 6.1+
- Xcode 14.0+
